# BRSET–mBRSET 患者级 DR 实验协议 v1

日期：2026-09-29

## 1. 分析单位与主任务

分析单位为患者，不是单张图像，也不是单只眼。

对患者 `p`、眼别 `e`、视野/图像 `v`，先生成眼级 ICDR：

`eye_grade[p,e] = max(ICDR[p,e,v])`

再生成患者级 ICDR：

`patient_grade[p] = max(eye_grade[p,left], eye_grade[p,right])`

主终点为患者级可转诊 DR（referable DR, rDR）：

`patient_rDR = 1(patient_grade >= 2)`

主任务仅纳入左右眼均至少有一张可分级、ICDR 标签非缺失图像的患者。这样在缺失眼压力测试中，即使模型只能看到一只眼，研究者仍知道患者的完整双眼真值。

### 次要终点

1. 患者级五分类：`patient_grade ∈ {0,1,2,3,4}`；
2. 患者级 any-DR：`patient_grade >= 1`；
3. 眼级 ICDR 预测，用于分析对侧眼是否错误传播；
4. 可选的威胁视力 DR：`patient_grade >= 3`，只作为探索性结果，因为样本较少。

## 2. 纳入和排除

### 主分析队列

- ICDR 标签存在；
- BRSET：`quality == Adequate`；
- mBRSET：`final_quality == yes`；
- 左右眼均存在至少一张满足上述条件的图像；
- 同眼多视野标签不同时，筛查主分析取最大 ICDR。

本地数据对应：

| 数据集 | 双眼可分级患者 | 患者级 ICDR 0/1/2/3/4 | rDR 阳性 |
|---|---:|---|---:|
| BRSET | 6,180 | 5,717 / 59 / 191 / 39 / 174 | 404（6.54%） |
| mBRSET | 1,231 | 845 / 95 / 195 / 27 / 69 | 291（23.64%） |

### 敏感性分析队列

- 保留质量不佳但 ICDR 有标签的双眼患者；
- BRSET 共 7,709 人、rDR 478 人；
- mBRSET 共 1,236 人、rDR 291 人；
- mBRSET 同眼多视野标签冲突患者单独报告，并比较 `max` 聚合与保守/共识聚合。

只有单眼且该眼阴性的患者不能在主分析中标为患者阴性，因为未知眼可能为阳性。糖尿病状态、图像质量和任何临床变量均不得参与真值生成。

## 3. 数据划分

### BRSET：唯一开发数据集

固定一次患者级 `70%/10%/20%` 划分：

- train：约 4,326 人，预计约 283 名 rDR；
- validation：约 618 人，预计约 40 名 rDR；
- internal test：约 1,236 人，预计约 81 名 rDR。

划分单位必须是 `patient_id`。同一患者的左右眼、所有图像、临床变量只能出现在同一个集合。

采用固定种子 `20260929`，用确定性贪心/迭代分层同时尽量平衡：

1. 患者级五级 ICDR；
2. 相机类型（Canon/Nikon/混合）；
3. 性别；
4. 年龄分箱（缺失、<50、50–64、65–74、>=75）；
5. 四项统一临床变量的缺失模式；
6. 双眼 ICDR 是否一致。

若联合分层产生过小单元，不删除样本；按上述优先级逐级放宽，患者级 ICDR 和相机分布必须优先保持。

划分后保存不可变清单：

`patient_id, split, patient_grade, patient_rDR, camera_group, sex, age_bin, metadata_mask, inter_eye_discordance`

清单生成后计算 SHA256 并冻结。之后所有模型共用同一清单，不为不同基线重新随机划分。

### mBRSET：完全外部测试

- 1,231 名主分析患者全部作为 external test；
- 不参与训练、早停、超参数选择、特征标准化、缺失值填补参数估计或阈值选择；
- 阈值只在 BRSET validation 上确定，再原样应用于 mBRSET；
- 若未来研究目标域校准或少样本适配，必须作为单独的次级实验重新划分，不能覆盖零样本外部验证结果。

### 防泄漏规则

- 图像归一化统计、表格均值/标准差、中位数填补及类别编码只由 BRSET train 拟合；
- 数据增强只作用于 train；
- 不根据 mBRSET 结果选择 epoch、模型或方法版本；
- 每次实验记录唯一 split manifest 和配置文件哈希；
- 类别权重只按 BRSET train 计算。

## 4. 最小基线

所有基线先使用同一个 ConvNeXt-Tiny 图像编码器、相同输入尺寸、增强、损失、训练轮数与患者划分。流程验证后，再用 DINOv3 ViT-S/16 或 RETFoundGreen 复现关键基线，而不是一开始铺开大量骨干。

| ID | 输入 | 目的 |
|---|---|---|
| B0 | 训练集患病率常数 | 检查指标与校准实现 |
| B1 | 临床表格数值 | 判断表格本身的预测能力 |
| B1-mask | 仅临床缺失掩码 | 直接测量缺失模式捷径 |
| B2 | 单眼独立图像预测，患者级取双眼最大概率 | 最核心图像基线，无跨眼交互 |
| B3 | 左右眼特征拼接/对称池化 | 测量普通双眼融合增益 |
| B4 | B3 + 临床表格与缺失掩码直接拼接 | 朴素多模态基线，也是拟议方法必须击败的对象 |

最小论文比较为 `B2 vs B3 vs B4 vs Proposed`；B0、B1、B1-mask 属于必要的诊断基线，训练成本很低。

### 多视野处理保持简单

- BRSET 每眼通常一张图；
- mBRSET 每眼约两张图；
- B2/B3/B4 均先对同眼所有图像特征做均值池化；
- 不允许在外部测试时只挑“最好看”的一张，除非质量选择规则已在 BRSET validation 上预注册。

## 5. 训练与模型选择

- 主损失：按 BRSET train 计算正类权重的 BCEWithLogits；
- 早停指标：BRSET validation AUPRC；
- 固定阈值：在 validation 上选择达到 90% 敏感度的最低阈值；
- 每个最终基线使用同一数据划分运行 3 个初始化种子；
- 不用 test 或 mBRSET 选择最优种子，报告三种子的均值，并保存各自预测用于患者级 bootstrap。

五分类次任务使用有序损失或普通交叉熵作为对照，但不要让五分类延迟主二分类流程。

## 6. 评价

### 主指标

- AUROC；
- AUPRC（注意其受患病率影响，不能直接把两库数值差完全解释为域泛化变化）；
- validation 冻结阈值下的敏感度、特异度、PPV、NPV；
- Brier score、ECE、校准截距和校准斜率。

### 次要指标

- 五分类 QWK、macro-F1 和 MAE；
- 单眼缺失、表格缺失和双眼不一致亚组表现；
- Canon、Nikon以及mBRSET手持相机分层结果。

所有置信区间和模型差异检验以患者为重采样单位，建议 2,000 次配对 bootstrap。不能以图像为单位计算置信区间。

## 7. 第一阶段判定标准

完成 B1-mask、B2、B3、B4 后再决定方法设计：

- 若 B4 内部提高但外部下降，且 B1-mask 有明显预测能力：重点做缺失捷径抑制；
- 若 B3 只在双眼一致者提高、在不一致者下降：重点做不对称感知门控；
- 若 B3/B4 在内外部都无增益：先检查标签、表格编码、图像质量和统计功效，不应直接增加模型复杂度；
- 若 B4 在所有条件均稳定优于 B2/B3：研究重点转向校准和缺失压力测试，而不是预设它一定失败。
