# Data directory

此目录只存放本地数据，除本说明和空目录占位文件外均被 Git 忽略。

```text
raw/        从原始来源获得的不可变数据；按 <dataset_id>/ 分目录
external/   他人生成或发布的派生数据、额外标注和辅助数据
interim/    清洗、解压或转换过程中的中间结果，可重新生成
processed/  可直接供训练/评估读取的最终派生数据
splits/     患者级 train/val/test 划分、交叉验证折及其生成日志
```

- 不修改 `raw/` 中的文件；预处理结果写入新的目录。
- 不混用患者级与图像级划分。若存在双眼或同一患者多次就诊，必须按患者分组。
- 不把患者姓名、病历号等直接标识符写入配置、日志或 Git 文档。
- 每个数据集在 `docs/datasets/` 建立数据卡，记录来源、许可、校验值、标签体系、纳排标准和统计信息。
- 大型压缩包、图像、表格、缓存及划分清单均保持在 Git 之外；需要共享时使用受控存储。
